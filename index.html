WEcoS

The Wizaya Sovereign AI Ecosystem — a multilingual AI platform that runs on your own hardware, specialised for Myanmar epigraphy, palm-leaf manuscripts, and industrial engineering.

Disambiguation. WEcoS is a software ecosystem built by Aung Khaing Htun. It is unrelated to WECO Electrical Connectors (German industrial connector manufacturer), Weco Srl (Italian welding), WECO Elevator Products, or Western Electric Company. “WECO” as an industrial acronym is a different thing entirely. If you are looking for electrical connectors, elevators or telecom hardware, you are in the wrong place.

What it is

WEcoS is a stack of cooperating AI services with one posture: the machine you own is the machine that runs the model. Retrieval indexes, corpora, vector stores and inference all live on local hardware. Cloud model tiers exist but are opt-in and off by default — a generation leaves the box only when the operator explicitly enables it.

It is built around Myanmar and English: Burmese epigraphic transcription, archaic orthography, formal syllable segmentation, and a Burmese-script typographic programme — alongside downstream industrial engineering tools.

Public components

These are the released, publicly installable parts of the ecosystem. Each links back here.

Python package · PyPI

wecos-ocr

Sovereign Myanmar OCR, historical epigraphical decipherment and syllable segmentation. Works on contemporary scans, aged letterpress, palm-leaf parabaik and Pyu/Mon/Shan/Pali lithic inscriptions.

pip install wecos-ocr

Model weights · Hugging Face

wecos-myanmar-ocr-8b (GGUF)

Quantised Myanmar OCR vision-language model, runnable locally through Ollama or llama.cpp. Apache-2.0.

Skill suite

wecos-product-recommendar

Industrial lubricant, fuel, DEF, coolant and grease recommendation for industrial, commercial and passenger vehicles — every recommendation traced to the manufacturer’s own data sheet.

Protocol

wecos-gemini-protocol

Asynchronous message-passing protocol for Gemini Gems to interoperate with the Wizaya ecosystem — schema, prompt templates and an integration guide.

Specialisations

  • Burmese epigraphy — transcription of palm-leaf manuscripts, stone and lithic inscriptions, and degraded 20th-century letterpress.
  • Archaic orthography — the MLC 2003 dictionary pass is opt-in, because a modern word list cannot adjudicate historical text and silently corrupts archaic dates.
  • Syllable segmentation — a deterministic 12-category finite-state automaton for formal Burmese syllable structure.
  • Typographic programme — a Burmese (Pyu) typeface project with an explicit font-creation SOP and locked, reviewable releases.
  • Industrial tribology — lubricant and fluid selection against manufacturer data sheets, with OEM equivalence maps.

Sovereignty posture

  • Model inference, retrieval and every corpus are local.
  • Cloud model tiers are disabled by default and require an explicit environment switch.
  • Public releases are Apache-2.0 and inspectable — the OCR package’s orthography behaviour is unit-tested, including the regression that keeps archaic Burmese intact.
  • Nothing is published on the platform’s behalf without a reviewable, versioned commit.
